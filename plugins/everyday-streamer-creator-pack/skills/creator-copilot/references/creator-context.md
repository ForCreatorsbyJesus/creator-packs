# Creator context

Maintain only context that improves future recommendations. Treat creator corrections as higher priority than prior assumptions.

## Context capsule

- Creator or channel name
- Primary platform and secondary destinations
- Audience and content promise
- Current goals and time horizon
- Sustainable cadence and available time
- Voice and recurring formats
- Tools, collaborators, and production constraints
- Boundaries and topics to avoid
- Current experiment
- Confirmed performance signals
- Open assumptions requiring validation

## Merge precedence

Use this order when inputs conflict:

1. the creator's newest explicit correction;
2. current creator-provided analytics or content;
3. direct observations from current public content;
4. derived patterns;
5. assumptions.

Retain the previous value only when it remains useful for history. Mark replaced material `superseded`; do not silently blend contradictory values.

## Status values

Use `active`, `superseded`, or `deleted`. A creator request to remove context overrides any value it would otherwise provide.
